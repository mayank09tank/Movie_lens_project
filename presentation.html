Issue 1: missing FROM-clause entry for table "tag"
Error:
ERROR: missing FROM-clause entry for table "tag" LINE 83: h.timestamp = tag.timestamp
Reason:
Query mein tag.timestamp likha tha, lekin tag naam ka koi table/alias defined nahi tha.
Wrong:
h.timestamp = tag.timestamp
Correct:
h.timestamp = tags.tag_timestamp
💡 Learning: Table name aur column name ko correctly reference karna zaroori hai.

Issue 2: movies_history mein expected history record nahi bana
Expected:
Toy Story (1995) | FALSE | INSERT Toy Story (1995) - VERSION 2 | TRUE | UPDATE
Actual mein sirf:
Toy Story - UPDATED... | TRUE | INSERT
Reason:
movies table mein data pehle hi update ho chuka tha. Jab history table populate ki gayi, tab current updated data hi history mein insert hua.
💡 Learning: History/SCD Type 2 ko maintain karne ke liye update ke time old aur new versions capture karne padte hain.

Issue 3: movies UPDATE ke baad movies_history automatically update nahi hui
Issue:
movies ↓ UPDATE ↓ movies_history automatic history record nahi bana.
Reason:
movies table par koi trigger configured nahi tha.
Query:
SELECT trigger_name, event_manipulation, action_statement FROM information_schema.triggers WHERE event_object_table = 'movies'; -- Result: 0 rows
💡 Solution: movies table par an appropriate UPDATE trigger create karna hoga jo movies_history mein old/new versions maintain kare.

Issue:
movies_cdc table create karne ke baad initially koi CDC record nahi aaya.
